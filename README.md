# Drug-Adverse-Event-Signal-Explorer

A Python-based pharmacovigilance data-analysis project exploring publicly available FDA adverse-event reports.

## 🎯 Objective

To explore reported adverse-event patterns associated with a selected medicine using healthcare data retrieved through the FDA openFDA API.

## 🔬 What This Project Does

- Retrieves publicly available FDA adverse-event reports using an API
- Cleans and preprocesses the reported data
- Identifies frequently reported adverse-event terms
- Explores reported patient age and sex
- Creates visualizations for data interpretation
- Summarizes important limitations of spontaneous-report data

## 🛠️ Technologies

- Python
- Pandas
- Matplotlib
- Requests
- FDA openFDA API
- Jupyter Notebook / Google Colab

## 📊 Analysis

The project includes:

1. Adverse-event frequency analysis
2. Patient age distribution
3. Reported sex distribution
4. Data visualization
5. Descriptive interpretation of the findings

## ⚠️ Important Limitation

This project analyzes spontaneous adverse-event reports. A reported adverse event does **not** establish that the medicine caused the event.

Spontaneous-report data can be affected by under-reporting, reporting bias, missing information, and other factors. Therefore, the analysis is descriptive and should not be interpreted as a clinical risk assessment or causal analysis.
